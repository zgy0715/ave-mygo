# 09 · 环境与依赖清单（开工前照此配置）

> 版本 v1.0（2026-10-15）。原则：**成熟方案优先，能引库不造轮子，不过早引入用不上的依赖**。
> 当前机器状态：JDK 17 ✅ / Node 22 ✅ / Git 2.55 ✅ / Ollama ✅ ｜ Maven ❌ / MySQL ❌ / Docker ❌ / IDEA ❓

## 1. 软件安装清单（按顺序）

| 优先级 | 软件 | 方案 | 说明 |
|---|---|---|---|
| 必装 | **IDEA Ultimate** | 官网下载 | 大三学生凭学校邮箱可申请 **JetBrains 免费学生许可**（jetbrains.com/shop/eform/students），Ultimate 全家桶免费——先去申请，一周内批 |
| 必装 | **MySQL 8.0.x** | MySQL Installer for Windows | 装时记住 root 密码；建议同时勾装 MySQL Workbench（图形客户端）；字符集选 utf8mb4 |
| 可缓 | Docker Desktop | 官网 | M6 部署阶段才需要，可开学后再装；不用它本机跑 MySQL 也行 |
| 不用装 | Maven | — | IDEA 自带捆绑版，且会用项目内 Maven Wrapper（`mvnw`），**单独安装反而多余** |
| 不用装 | 前端工具链 | — | Node 22 已就位，Vite 脚手架自带全部 devDependencies |

> IDEA 能不能写全项目？**能，一个软件全包**：后端 Spring Boot（本行）、前端 Vue（Ultimate 的 Vue 支持足够，不必装 WebStorm）、数据库（内置 Database 面板直连 MySQL，替代 Navicat）、接口调试（内置 HTTP Client，替代 Postman 的大部分场景）。

## 2. 后端 Maven 依赖（backend/pom.xml，全部选成熟主流）

| 依赖 | 用途 | 选型理由（成熟方案） |
|---|---|---|
| spring-boot-starter-web | REST 接口 | 事实标准 |
| spring-boot-starter-data-jpa | ORM | 企业主流；配 Hibernate 自动建表关闭、DDL 由 Flyway 管 |
| **spring-boot-starter-security** | 认证授权框架 | **不手写登录拦截器**——过滤器链、密码编码、401/403 语义全部交给它 |
| **jjwt-api / jjwt-impl / jjwt-jackson** (0.12.x) | JWT 生成校验 | 配合 Spring Security 成熟组合，不自研 token 格式 |
| spring-boot-starter-validation | 参数校验 | `@Valid` + 注解，不自写 if 校验 |
| **flyway-core + flyway-mysql** | 数据库迁移 | 版本化 SQL，绝不手工改表 |
| mysql-connector-j | MySQL 驱动 | runtime |
| springdoc-openapi-starter-webmvc-ui | Swagger 文档 | 自动生成，不自写文档页 |
| lombok | 消样板代码 | @Data/@Builder/@RequiredArgsConstructor |
| spring-boot-starter-test + testcontainers(mysql) + spring-security-test | 测试 | 用真 MySQL 跑集成测试，不污染本地库 |
| ~~spring-boot-starter-data-redis~~ | **V1 不引** | 防超卖用 DB 原子更新已够（docs/05 §5.1）；M5 做性能对比时再引，避免过早优化 |

## 4. 配置清单

### 4.1 Maven 国内加速（装完 IDEA 第一件事）

`~/.m2/settings.xml` 配阿里云镜像，否则依赖下载极慢：

```xml
<mirror>
  <id>aliyunmaven</id>
  <mirrorOf>central</mirrorOf>
  <url>https://maven.aliyun.com/repository/public</url>
</mirror>
```

### 4.2 `.env`（backend，gitignore，提供 .env.example 模板）

| 变量 | 示例值 | 说明 |
|---|---|---|
| DB_URL | jdbc:mysql://localhost:3306/bandori_live?useSSL=false&serverTimezone=Asia/Shanghai |库名定 `bandori_live` |
| DB_USERNAME | root | |
| DB_PASSWORD | （你的 MySQL 密码） | |
| JWT_SECRET | （≥32 位随机串） | 生产换新值 |
| JWT_EXPIRATION_HOURS | 24 | |
| OLLAMA_BASE_URL | http://localhost:11434 | M7 用，已就位 |

### 4.3 application.yml 关键项

```yaml
spring:
  jpa:
    hibernate.ddl-auto: validate   # 表结构只信 Flyway，JPA 只做校验
    open-in-view: false
  flyway:
    enabled: true
    locations: classpath:db/migration
logging:
  level:
    com.bandori: DEBUG
    org.hibernate.SQL: DEBUG       # 开发期看 SQL，上线前改 INFO
```

### 4.4 其他一次性配置

- [ ] GitHub 建远程仓库（名字建议 `bandori-live`），本地 main 推上去
- [ ] MySQL 建库：`CREATE DATABASE bandori_live DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;`
- [ ] IDEA 安装免费插件：Lombok（新版内置）、.env files support、MyBatisX 不需要（JPA 方案）
- [ ] npm 可选换国内源：`npm config set registry https://registry.npmmirror.com`

## 5. 开工顺序（M1 当天）

1. 申请 JetBrains 学生许可 → 装 IDEA Ultimate
2. 装 MySQL 8 → 建库 bandori_live → settings.xml 配阿里云镜像
3. IDEA 里 Spring Initializr 生成工程（勾选 §2 的依赖）→ 按 docs/05 写 `V1__init.sql` → Flyway 首跑成功
4. 前端 `npm create vue@latest` → tailwind 初始化
5. 打通端到端：一个 `GET /api/v1/health` 返回 `{code:0,message:"ok",data:{...}}`，前端首页能显示
