## 默认分发范围

此前 Git 跟踪的 MV、首帧、封面、立绘、标识、favicon 和含这些素材的页面截图，
缺少可核实的分发授权记录，现从当前 Git 跟踪中移除。本机文件保留并忽略，不自动删除，
不将未知来源填写成已获授权。逐文件路径、大小和 SHA-256 见 assets-manifest.csv。
清单中 source_url 为空代表没有可核实的逐文件来源，permission_evidence 为空代表没有授权证据。
截图由项目生成，所包含第三方画面的权利仍未核实。

本地 npm run dev 默认读取 frontend/public 中已有的素材，方便检查原有页面效果；
INCLUDE_LOCAL_ASSETS=0 可显式关闭。本地显示不代表这些素材已取得公开分发授权。
生产构建 npm run build 默认不打包 public；GitHub CI 验证这个不带素材的构建。
没有本地素材的新克隆使用渐变与文字降级。

## 服务器保留素材

代码与服务器素材分别维护。部署脚本在自动拉取代码及前端构建之前调用 scripts/preserve-assets.sh，
从 frontend/public、旧 frontend/dist 依次补齐以下持久目录，已有文件不覆盖：

- var/site-assets/img/：封面、立绘、乐队标识等，Nginx 提供 /img/。
- var/site-assets/assets/：两个 band-*-poster.jpg，Nginx 提供对应 /assets/ 路径。
- var/site-assets/favicon.ico：站点图标。
- var/hero-assets/：两个 band-*-720p.mp4，仍供后台上传和 Nginx 使用。

这些目录不入 Git，前端构建清理 dist 时不会清理它们。首次从旧部署更新前，先备份
frontend/public、frontend/dist、backend/.env 及已有 var 下的素材目录；不要在保留素材前单独重建前端。
即使 git pull 已移除了旧 public 文件，只要旧 dist 尚未被重新构建，脚本仍可从中补齐素材。
新机器仅克隆代码不会获得素材；应将自行准备的素材按上述目录单独上传，然后部署。
替换已保留的素材时直接更新对应持久文件；脚本仅补缺失文件，以免覆盖管理端上传或人工替换。
该保留过程不核验、下载或授予素材使用权，公开展示前仍须自行确认适用授权。

## 替换流程

1. 使用自己制作或已明确获准公开展示、分发的图片和视频；逐文件记录来源链接、权利方、
   许可文本/授权证据、适用范围及 SHA-256，更新清单后再决定是否加入版本控制。
2. 本地素材路径：封面 frontend/public/img/covers/，标识 frontend/public/img/logo/，
   其余乐队和成员图使用数据库中的本地路径；Hero 为 frontend/public/assets/band-{mygo|mujica}-720p.mp4，
   可选首帧为 band-{mygo|mujica}-poster.jpg。保留同路径即可替换，无需修改冻结迁移。
3. 本地开发无需开关；需要让独立构建产物也包含素材时，在确认使用权后显式设置 INCLUDE_LOCAL_ASSETS=1。
   PowerShell 示例：$env:INCLUDE_LOCAL_ASSETS='1'；Bash 示例：INCLUDE_LOCAL_ASSETS=1 npm run build。
   此时 public 中的本地文件会被复制到 dist；服务器的持久素材方案无需开启该打包选项。
4. 管理端上传仅供上传者有权使用的 MP4；应用不会判断内容权利，也不自动下载、转码或更新首帧。
   Ubuntu 上传目录为 var/hero-assets，部署自动从现有 public 或旧 dist 补齐缺失槽位，保留已有上传。

官方试听、播放器和外部站点链接仍由浏览器直接访问原站，不视作本站取得素材再分发授权。
Google Fonts 在浏览器端外链加载；若离线自托管字体，须另附对应字体许可证。
默认构建后可运行 `python scripts/check-assets.py --dist`；CI 同样检查未核实素材未被重新跟踪或打入产物。

## 历史与发布限制

此次仅从当前版本移除素材，旧 Git 提交仍可能包含这些文件。没有重写历史或强制推送。
如要让公开仓库所有历史版本也不携带这些文件，发布前需选择新建只含当前代码的仓库，
或在单独备份与协作协调后进行历史清理；这不由普通修复提交自动完成。
新克隆默认可运行无本地素材界面。Ubuntu/Nginx 实际部署、公开平台条款与具体素材许可由发布时验收。
