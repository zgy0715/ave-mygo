# 06 · 接口设计（字段级）

> 版本 v1.0（2026-10-15）。Base URL：`/api/v1`。所有响应统一 `{code, message, data}`。
> 鉴权：登录后请求头 `Authorization: Bearer <token>`（JWT，有效期 24h）。

## 1. 统一规范

### 1.1 响应结构

```json
{ "code": 0, "message": "ok", "data": { } }
```

分页数据 data 结构：

```json
{ "list": [ ], "total": 100, "page": 1, "pageSize": 12 }
```

### 1.2 业务错误码表

| code | HTTP | 含义 |
|---|---|---|
| 0 | 200 | 成功 |
| 40001 | 400 | 参数校验失败（message 说明具体字段） |
| 40101 | 401 | 未登录 / token 过期 |
| 40301 | 403 | 无权限（非 ADMIN 访问管理接口 / 账号被封禁） |
| 40401 | 404 | 资源不存在 |
| 40901 | 409 | 库存不足 |
| 40902 | 409 | 状态冲突（重复支付 / 状态不允许操作） |
| 40903 | 409 | 超出限购数量 |
| 40904 | 409 | 用户名已存在 |
| 50001 | 500 | 系统内部异常 |

### 1.3 命名约定

- 路径全小写 kebab-case，资源复数；查询参数 camelCase
- 时间一律 ISO 字符串 `yyyy-MM-dd HH:mm:ss`；金额数字（元，两位小数）

## 2. 认证模块 /auth

### POST /auth/register
请求：`{ "username": "tomori_fan", "password": "Abc12345", "nickname": "灯厨" }`
校验：username 3~32 位 `[a-zA-Z0-9_]`；password 6~32 位且含字母数字。
响应 data：`{ "userId": 1001, "username": "tomori_fan" }`
错误：40001 / 40904 用户名已存在

### POST /auth/login
请求：`{ "username": "tomori_fan", "password": "Abc12345" }`
响应 data：`{ "token": "eyJ...", "expiresIn": 86400, "user": { "userId": 1001, "username": "...", "nickname": "灯厨", "role": "USER" } }`
错误：40001 / 40101 用户名或密码错误 / 40301 账号已封禁

### GET /users/me　（登录）
响应 data：`{ "userId", "username", "nickname", "role", "avatarUrl", "createdAt" }`

### PUT /users/me　（登录）
请求：`{ "nickname": "新昵称", "avatarUrl": "https://..." }`（字段均可选）

## 3. 内容模块（公开）

### GET /songs
查询参数：`bandId`、`albumId`、`tag`（单值）、`keyword`（标题前缀/包含匹配）、`page`(默认1)、`pageSize`(默认12，最大50)、`sort`（`release_desc`默认 / `release_asc` / `title_asc`）
响应 data.list[] 元素：

```json
{ "id": 1, "title": "壊れそうな僕らは", "bandId": 1, "bandName": "MyGO!!!!",
  "albumId": 5, "albumName": "迷星叫", "duration": 245, "coverUrl": "...",
  "audioUrl": "...", "mvUrl": "...", "mvPlatform": "BILIBILI", "tags": ["燃"], "releaseDate": "2023-04-12" }
```

### GET /songs/{id}
响应 data：上元素 + `album` 完整信息 + `mvEmbedReady`（boolean，前端决定能否 iframe embed）
错误：40401

### GET /albums?bandId=　GET /members?bandId=
列表结构，字段见 docs/05 表定义（snake → camel 转换）。

### GET /events
查询参数：`status`（PUBLISHED/ENDED）、`bandId`、`page`、`pageSize`
响应 data.list[]：`{ "id", "title", "bandName", "posterUrl", "venue", "status", "minPrice", "nextSessionTime" }`
（minPrice/nextSessionTime 为计算字段：在售票档最低价、最近一场开演时间）

### GET /events/{id}
响应 data：演出详情 + `sessions[]`：

```json
{ "id": 1, "title": "MyGO!!!! 5th LIVE", "bandName": "MyGO!!!!", "description": "...",
  "posterUrl": "...", "venue": "武道馆", "status": "PUBLISHED",
  "sessions": [ { "id": 10, "name": "昼场", "startTime": "2026-11-01 14:00:00",
      "endTime": "2026-11-01 16:00:00", "status": "ONSALE",
      "ticketTypes": [ { "id": 100, "name": "S席", "price": 9800.00,
          "availableStock": 3, "totalStock": 50, "maxPerUser": 4, "status": "ENABLED" } ] } ] }
```

> `availableStock = total_stock - sold_count` 计算得出；管理员端额外返回 `soldCount`。

## 4. 订单模块 /orders（登录）

### POST /orders　（下单，P0 核心）
请求：`{ "sessionId": 10, "ticketTypeId": 100, "quantity": 2 }`
响应 data：

```json
{ "orderNo": "BL202610151234567890", "status": "PENDING_PAYMENT",
  "unitPrice": 9800.00, "totalAmount": 19600.00,
  "payDeadline": "2026-10-15 21:40:00" }
```

错误：40001 / 40101 / 40401 场次或票档不存在 / **40901 库存不足** / 40902 场次非销售中 / 40903 超限购

### POST /orders/{orderNo}/pay　（模拟支付，幂等）
无请求体。仅本人。
响应 data：`{ "orderNo", "status": "PAID", "paidAt": "..." }`
逻辑：状态 PENDING 且未超时 → PAID；已超时 → 40902；重复调用返回已支付结果（幂等，不报错）。

### GET /orders/my?status=&page=&pageSize=
status 可选 PENDING_PAYMENT/PAID/CANCELLED/EXPIRED/REFUNDED
响应 data.list[]：`{ "orderNo", "eventTitle", "sessionName", "sessionStartTime", "ticketTypeName", "quantity", "totalAmount", "status", "payDeadline", "createdAt" }`

### GET /orders/{orderNo}
订单详情：上元素 + `unitPrice, paidAt, cancelledAt, refundedAt, refundReason`。仅本人或 ADMIN。40401（他人订单一律 404，不泄露存在性）

### PATCH /orders/{orderNo}/cancel
仅本人、仅 PENDING。响应 data：`{ "orderNo", "status": "CANCELLED" }`；40902 状态不允许

## 5. 收藏与歌单（登录，P1）

- `GET /favorites?type=SONG|EVENT` → 列表（SONG 返回歌曲完整字段，EVENT 返回演出摘要）
- `POST /favorites` `{ "targetType": "SONG", "targetId": 1 }` → 201；重复收藏返回 0（幂等成功）
- `DELETE /favorites/{targetType}/{targetId}` → 204
- `GET/POST /playlists`、`PUT /playlists/{id}`、`DELETE /playlists/{id}`
- `POST /playlists/{id}/items` `{ "songId": 1 }`、`DELETE /playlists/{id}/items/{songId}`、`PATCH /playlists/{id}/items/sort` `[{"itemId":1,"sort":2},...]`

## 6. 管理端 /admin（全部要求 ADMIN）

### 歌曲与资料
- `POST/PUT/DELETE /admin/songs`、`/admin/albums`、`/admin/members`：请求体 = docs/05 表字段（camelCase），DELETE 为软删
- `PATCH /admin/songs/{id}/status` `{ "status": 0 }`（上架/下架）

### 演出与场次与票档
- `POST /admin/events`：title/bandId/description/posterUrl/venue → 创建后 status=DRAFT
- `PATCH /admin/events/{id}/publish`：校验至少 1 个场次且每场次至少 1 个启用票档，否则 40902
- `PATCH /admin/events/{id}/cancel`：已产生 PAID 订单时必须先处理退款，否则 40902
- `POST /admin/events/{id}/sessions`：name/startTime/endTime/saleStartTime；校验 end > start、saleStart ≤ start
- `POST /admin/sessions/{id}/ticket-types`：name/price/totalStock/maxPerUser；**仅 NOT_OPEN 状态可增改票档库存**
- `PUT /admin/ticket-types/{id}`：改价/改库存（只能增加 totalStock，不能减少到低于 sold_count，否则 40902）

### 订单与退款
- `GET /admin/orders?status=&orderNo=&userId=&eventId=&page=`（多维筛选）
- `PATCH /admin/orders/{orderNo}/refund` `{ "reason": "..." }` → REFUNDED + 回滚库存；演出已开演则 40902

### 数据看板
- `GET /admin/stats/overview` → `{ "todaySales": 19600.00, "todayOrders": 2, "monthSales": 0, "totalUsers": 15, "onSaleEvents": 3 }`
- `GET /admin/stats/sales-trend?days=30` → `{ "list": [{ "date": "2026-10-15", "sales": 19600.00, "orders": 2 }] }`（按 PAID+REFUNDED 实付口径）
- `GET /admin/stats/ticket-sales?eventId=` → 各演出各票档 `{ "list": [{ "ticketTypeName": "S席", "soldCount": 10, "totalStock": 50, "salesAmount": 98000.00 }] }`

### 用户管理
- `GET /admin/users?keyword=&page=` → `[{ "userId", "username", "nickname", "role", "status", "orderCount", "createdAt" }]`
- `PATCH /admin/users/{id}/status` `{ "status": 0 }`（封禁/解封；不能封禁自己，40902）
