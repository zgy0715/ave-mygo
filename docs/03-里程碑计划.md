## 二、启动日（Day 1）标准动作

1. 定方向 → 写 `docs/04-需求说明.md`（一段话背景 + 核心功能列表）
2. 锁栈 → 更新 `docs/01-技术选型.md` 待定项
3. 画核心数据模型（表 + 关系，落 `sql/V1__init.sql`）
4. 前后端脚手架落地，打通一条端到端最小链路（前端一个页面 → 后端一个接口 → 查一条 MySQL 数据）

## 三、通用里程碑模板（企业级项目骨架）

| 里程碑 | 内容 | 验收标准 |
|---|---|---|
| M1 基础设施 | 脚手架、数据库、统一响应、日志、全局异常 | 端到端 hello-world 链路通 |
| M2 用户体系 | 注册/登录、JWT 鉴权、权限拦截 | 未登录访问受保护接口返回 401 |
| M3 核心业务 | （按方向填充，如商品/文章/工单）CRUD + 分页 + 搜索 | 核心流程可走通 |
| M4 前端体验 | 列表/表单/状态管理/加载与错误态 | 移动端可正常浏览 |
| M5 质量加固 | 参数校验、事务、日志补全、关键路径测试 | 异常输入不产生脏数据 |
| M6 部署交付 | Docker Compose 一键起（app + mysql + nginx）、README 部署文档 | 新机器 10 分钟跑起来 |
