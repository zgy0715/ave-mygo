### 2. 小灯在云端仍不可用（代码两处缺口）

- **现状**：`OllamaStreamLlm` 里 `Authorization` 出现 0 次；`tool_calls` 仍按 Ollama「整块到达」解析。
- **为什么没做**：接云 API 属改代码，等明确指令；且用户当时要求先停手。
- **要改的地方**：
  1. 请求头：`apiKey` 非空时加 `Authorization: Bearer ${LLM_API_KEY}`（本地 Ollama 留空即不发）；
  2. 流式解析：OpenAI/DeepSeek 的 `tool_calls` 是**按 index 增量分片**，必须按 index 累加 `arguments` 字符串；
     现有实现每次 chunk 直接当完整调用，接云 API 会拿到半截 JSON，工具全废；
  3. 模型探测：云端不能去探 `localhost:11434/api/tags`，改为「没配 `LLM_MODEL` 就启动报错」。

- **工作量**：约 30~40 分钟（含补一个「增量分片拼接」的单测）。
